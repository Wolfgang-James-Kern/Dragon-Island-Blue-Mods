# Manual Encounters

This is a manifest-format mod for a Dragon Island Blue Mod Launcher. It sets
the random encounter rate to zero in all 17 worlds registered by the original
game, including the Underworld.

With the mod enabled, travelling to an ordinary encounter-capable point of
interest should not start a random battle. The POI's encounter definition is
left intact, so deliberately selecting its battle option can still force an
encounter.
